# Healthcare Utilization & Cost Analytics

## Project Overview

This project analyzes synthetic healthcare data generated by Synthea to explore patient encounters, healthcare utilization patterns, and medical costs.

The project follows an end-to-end data analytics workflow, from data cleaning and validation in Python to relational data modeling in PostgreSQL and interactive reporting in Power BI.

## Objectives

- Analyze healthcare utilization trends over time.
- Explore encounter types and patient visit patterns.
- Examine healthcare costs and payer coverage.
- Design a relational PostgreSQL database.
- Build a reproducible ETL pipeline using Python and pandas.
- Develop an interactive Power BI dashboard.

## Tech Stack

Python · pandas · PostgreSQL · SQL · Power BI · Git

## Data Source

Synthetic healthcare data generated by Synthea. No real patient records are used.
